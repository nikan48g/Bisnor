نسخه **5.1.3 Beta بیسنور** با تمرکز روی کاتالوگ زنده ایران‌فلیکس، هم‌ترازی نسخه Windows با وب‌اپ Tizen و جلوگیری از بازگشت داده‌های قدیمی منتشر شده است. 🌐

## 🎬 Live IranFlix Catalog

- حذف کامل snapshot و کاتالوگ آفلاین قدیمی از Windows و Tizen
- حذف فایل‌های `real_catalog_seed.json` از بسته‌های نهایی
- دریافت فیلم‌ها، سریال‌ها، جستجو، فصل‌ها و قسمت‌ها فقط از Live API ایران‌فلیکس
- هماهنگ‌سازی سرورهای وب‌اپ با سرورهای مورد استفاده نسخه Android
- بارگذاری چندصفحه‌ای Explore مطابق Android: چهار صفحه IMDb، سه صفحه فیلم‌های جدید و سه صفحه سریال
- اتصال مستقیم جستجوی Windows و Tizen به endpoint زنده؛ پشتیبانی صحیح از عنوان‌های چندکلمه‌ای مانند One Piece
- حفظ رفتار امن در زمان قطعی API؛ نمایش ندادن داده فیک یا قدیمی

## 🖥️ Windows Desktop Improvements

- همگام‌سازی کلاینت داده Windows با کلاینت API-only تایزن
- کاهش محسوس حجم فایل JavaScript کاتالوگ
- افزایش زمان انتظار bridge برای جلوگیری از timeout زودهنگام درخواست‌های واقعی
- حذف پذیرش ناامن گواهی TLS نامعتبر
- حفظ پشتیبانی WebView2، پلیر داخلی، پلیرهای خارجی و IDM

## 📺 Tizen Web App Improvements

- حذف وابستگی عمومی و ناپایدار AllOrigins
- استفاده از Live API و proxy اختصاصی قابل تنظیم
- اضافه شدن سرور سوم ایران‌فلیکس برای هم‌ترازی با Android
- جلوگیری از بسته‌بندی accidental داده‌های seed در WGTهای بعدی

## ⚙️ Build, CI & WinGet

- اضافه شدن اسکریپت همگام‌سازی وب‌اپ Windows و Tizen
- اضافه شدن کنترل CI برای جلوگیری از بازگشت کاتالوگ آفلاین
- جلوگیری از Release در صورت اختلاف کلاینت داده Windows با منبع API-only
- اضافه شدن مانیفست WinGet نسخه 5.1.3
- انتشار هم‌زمان APK اندروید و Installer ویندوز

## 📱 Android Package

- ارتقا نسخه به `5.1.3` با `versionCode 30`
- شامل آخرین اصلاحات پخش، تم و تنظیم Auto Next
- حفظ قرارداد Live API ایران‌فلیکس به‌عنوان مرجع اصلی کاتالوگ

## ⚠️ Beta Notice

این نسخه **Pre-release / Beta** است.

دسترسی به محتوای زنده به وضعیت سرورهای ایران‌فلیکس و شبکه کاربر وابسته است. در صورت قطع API، برنامه عمداً کاتالوگ فیک یا snapshot قدیمی نمایش نمی‌دهد.

در صورت مشاهده مشکل، لطفاً آن را در GitHub Issues گزارش کنید.

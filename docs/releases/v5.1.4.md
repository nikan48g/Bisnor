نسخه **5.1.4 بیسنور** با تمرکز روی رفع کامل مشکل ثبت‌نام، حفاظت از اطلاعات حساب‌ها و انتقال امن کاربران قدیمی منتشر شد. 🔐

## ✅ Registration Fixed

- رفع خطای ثبت‌نام گزارش‌شده در Issue #7
- اصلاح شناسه داخلی Username برای سازگاری با Supabase Auth
- حفظ تجربه ساده ثبت‌نام فقط با **نام کاربری و رمز عبور**
- جلوگیری از نمایش موفقیت کاذب در صورت صادر نشدن Session
- اصلاح پیام‌های خطای ثبت‌نام و تشخیص بهتر مشکل پیکربندی حساب

## 🔐 Stronger Account Security

- فعال شدن Row Level Security روی جدول حساب‌های قدیمی
- قطع کامل دسترسی مستقیم کاربران ناشناس و واردشده به اطلاعات Legacy
- جلوگیری از خواندن یا تغییر مستقیم هش رمز، Favorites و Playlists
- اضافه شدن Policy مالک‌محور برای ساخت Profile
- حفظ Session و Profile Sync تحت سیاست‌های امن Supabase

## 🔄 Safe Legacy Account Migration

- حفظ تمام حساب‌های قدیمی بدون حذف اطلاعات
- انتقال خودکار Favorites، Playlists و Avatar
- تأیید رمز قدیمی به‌صورت Server-side
- عدم انتقال یا افشای Password Hash
- علامت‌گذاری امن حساب قدیمی پس از Claim موفق
- مهاجرت فقط برای کاربر واردشده با Username مطابق Profile

## 🗄️ Profile Sync Fixes

- رفع ناسازگاری timestamp عددی با ستون‌های `timestamptz`
- اصلاح ساخت پروفایل پس از ثبت‌نام
- اصلاح همگام‌سازی Avatar، Favorites و Playlists
- جلوگیری از از بین رفتن داده‌های منتقل‌شده هنگام اولین Sync

## 🧪 Verified End-to-End

این نسخه با جریان واقعی Supabase آزمایش شده است:

- ثبت‌نام و دریافت Session
- ورود مجدد با Username و Password
- ساخت و خواندن Profile تحت RLS
- انتقال واقعی Favorites، Playlists و Avatar از حساب Legacy
- مسدود بودن دسترسی مستقیم `anon` و `authenticated` به جدول قدیمی
- اجرای موفق Unit Testهای Android
